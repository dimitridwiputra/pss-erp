## Per-slice completion record

For every new screen, record its feature ID and AC/NC/TS references, user role and scoped route, domain owner, typed contract version, permitted actions, loading/empty/error/offline behavior, screenshot states, test commands and output, release gate, and any unresolved Product/Ops decision. Do not mark a feature complete from a visible screen alone.
