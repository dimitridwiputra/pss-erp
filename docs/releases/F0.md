### What the 30 September work did not change

Recorded explicitly so a green local run is not mistaken for gate progress. Each of these needs a person, an account, or an approved business value:

- **No hosted evidence exists.** The Terraform stack has never been applied; `gcloud auth` has no credentialed account, so no budget has been incurred and no hosted run of anything has happened.
- **No Git remote and no branch protection.** The repository is local only, so `.github/workflows/ci.yml` has never executed against this code. The gate's first criterion therefore remains unproven.
- **ADR-0009 and ADR-0012 are Proposed, not Accepted.** No owner has signed either.
- **`audit.audit_entry` is still unpartitioned in production terms.** The prepared partitioned table exists and is tested; the swap needs OD-19.
- **A successful browser approval decision is still uncovered**, because the only role holding a decision permission is MFA-required and a password-only local sign-in cannot satisfy `requireRecentMfa`.
- **DQ-001.AC05 is not implemented and is not claimed.** The overdue notification depends on NTF-001.
- **`EXCEPTION_*`, `CONFIG_VALUE_CHANGED`, `FEATURE_FLAG_CHANGED`, and `DOCUMENT_NUMBER_VOIDED` are catalogued but unpublished.** They have no registered payload schema, so the outbox correctly rejects them; audit entries are the record until the contracts owner registers them.
