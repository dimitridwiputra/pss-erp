# Sprint 0 source-data request drafts

**State: drafts only; not sent.** The Implementation Plan S0.7–S0.8 requires formal requests and named contacts. These drafts make the requests reviewable without inventing an owner, file format, source-system authority, or data value. Send only through the authorized PSS Operations/IT and Finance channels.

## Operations and IT: ND6 and FoxPro

Subject: Sampel dan akses sumber data untuk perancangan PSS Operating Platform

Mohon tunjuk PIC teknis dan PIC bisnis untuk setiap instance ND6 serta setiap cabang FoxPro yang termasuk lingkup proyek. Kami memerlukan contoh ekspor dan kamus data yang menjelaskan nama tabel/file, kolom, tipe data, kunci identitas, hubungan antar dokumen, status, waktu pembaruan, dan cara memperoleh perubahan berikutnya. Sertakan cara akses yang disetujui, frekuensi ekspor, periode data contoh, jumlah baris/kontrol total, serta batasan lisensi atau keamanan dari principal.

Untuk setiap contoh, mohon jelaskan asal instance/cabang, waktu penarikan, versi format, dan pihak yang berwenang menjelaskan arti field. Gunakan sampel sintetis atau data yang telah dimasking bila memungkinkan; jangan mengirim kata sandi atau data pelanggan pribadi lewat email biasa. Kami akan menyimpan raw input dan provenance sebelum mapping, lalu mencatat record yang gagal atau tidak dikenal di antrian pengecualian.
