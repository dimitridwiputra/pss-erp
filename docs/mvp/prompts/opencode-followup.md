## Pitfalls stream A hit (save yourself the time)

- **`apps/web` may not import `pg` (PLT-002), not even in tests.** A fixture that needs the database is a root script under `scripts/`, called through `execFileSync` (see `scripts/seed-mvp-foreign-branch-sale.mjs`).
- **Only one `next dev` per app.** Playwright's CI config starts its own on :3100, so stop yours first. Never run a full `pnpm build` while `next dev` runs: it overwrites `.next`.
- **Fresh worktree:** run `pnpm install`, then `pnpm typecheck` before your first commit. The pre-commit hook needs `packages/contracts/dist`.
- **Real-stack tests:** use a separate database (`PSS_DEMO_DATABASE=pss_mvp_e2e`, DEMO_RUNBOOK §7) so you don't wipe anyone's local data.
- **Scanner input** arrives as fast Enter-terminated bursts. If you build a scan field, queue submissions rather than disabling the submit button: a disabled submit blocks Enter. See `drainScans` in `apps/web/app/kasir/kasir-counter.tsx`.
- **`@pss/audit` requires at least one audit entry per command transaction.** A no-op path appends its own entry (ADR-0013 4b).
