## Pitfalls stream A hit (save yourself the time)

- **Fresh worktree:** run `pnpm install`, then `pnpm typecheck` (or `pnpm --filter @pss/contracts build`) before your first commit. The pre-commit hook needs `packages/contracts/dist`.
- **Only one `next dev` per app.** Playwright's CI config starts its own on :3100, so stop your dev server first or it fails with "webServer was not able to start".
- **Don't run a full `pnpm build` while `next dev` runs.** It overwrites `.next` and breaks the dev server ("missing required error components").
- **Real-stack tests:** use a separate database (`PSS_DEMO_DATABASE=pss_mvp_e2e`) so you don't wipe anyone's local data (DEMO_RUNBOOK §7).
- **`@pss/audit` requires at least one audit entry per command transaction.** A no-op path must append its own entry (ADR-0013 4b).
