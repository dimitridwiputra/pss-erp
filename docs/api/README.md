# API catalog

`openapi.json` is generated by `@pss/contracts` from the shared health and problem response schemas. It currently documents the API process's `/health/live` and `/health/ready` routes, including the default RFC 9457 error response. All four backend processes use the same NestJS error filter. Business endpoints and request validation have not been implemented.

Regenerate with `pnpm --filter @pss/contracts build`; `pnpm contracts:check` rejects stale output and route/response changes incompatible with `openapi-baseline.json`. Review any baseline change against the previous main branch before merging; automatic main-branch comparison remains pending.
