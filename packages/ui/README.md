# @pss/ui

Shared PSS design tokens from `docs/DESIGN_SYSTEM.md` §§3 and 5. Import `@pss/ui/tokens.css` once in an app root layout; JavaScript consumers can use the typed `colors`, `spacing`, and `radius` exports.

This is the UX-001 token foundation. Shared components, page templates A–D, Storybook state coverage, and axe checks are still pending. No business logic belongs in this package.
